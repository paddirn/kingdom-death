# v0.1.5 — Family, Proficiency and images

Adds Survivor Family and Image tabs, reciprocal world-Survivor relationships, Proficiency Items with generated names and keyword tags, and UUID-based proficiency linking. Shared Item image selection and preview use native images; Survivor avatar and prototype-token images remain independent.

Refines the Survivor layout with a live Sex color bar, read-only progression totals, below-field numeric controls, corrected radio styling and full-width Condition & Notes with five custom counters. Existing Actor data, proficiency text/XP, gear, inventory and Specials are retained with additive defaults.

Family and image changes save immediately; ordinary fields and proficiency links use Save Changes. Family edits require ownership of all affected Actors, otherwise a GM must apply them. Coordinate simultaneous family edits; interrupted updates produce an inspection/repair warning.

Validated with 53 Node and 9 Python tests plus syntax, template, manifest, module-path and ZIP checks. Targets Foundry 14.365 only. Actual Foundry rendering, reload persistence and Forge file dialogs remain unverified. After updating, restart/reload Forge and follow docs/family-proficiency-images.md for the manual acceptance checklist.

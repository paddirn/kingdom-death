# v0.1.9 — Survivor injuries and Item sheet refinements

Survivors can record individual severe injuries alongside armor and Light/Heavy injuries at each body location. The Specials tab adds 20 manual impairment flags. Existing impairment notes remain readable. The sheet also tracks Overcharge, Embolden and Cannot use Abilities. GMs can choose optional anatomical icons in world settings.

Gear inventory displays Gear and Resources. Item sheets group Name with Keywords and Proficiency Type with Rank. Gear shows directional affinity selectors and a vertical Attack Profile. Item preview uses a button to open the Foundry image viewer.

This release targets Foundry 14.365. After updating on Forge, restart the game and reload clients. Rendering, world setting updates across clients and injury persistence still need verification in the running target build. See docs/injury-records.md for the checklist.
